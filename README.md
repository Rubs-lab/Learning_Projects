## Linear Regression Engine in C

This project presents a simple command-line linear regression engine written in C that calculates statistical measures from data sets provided by the user and is used to make mathematical predictions. This project was built to strengthen my understanding of statistics, C programming, arrays, functions, and the mathematical foundations of linear regression.

## Technology

C language, Standard C library (stdio.h), Math library ( Math.h), Command line Interface

It is an ongoing project, where the current files will serve as a frame for the final project of developing a linear regression engine for a larger data set that I have been interested in making predictions with.

## Features:

Mean, Variance, Standard Deviation, Covariance, Correlation Coefficient, Regression Slope, Regression Intercept, and Predicted Y Values for Multiple User-provided X Values

The program also includes input validation to prevent the insertion of invalid datasets and prediction sizes.

## Possible Improvements

Adding more regression models, Improving input validation, Adding data visualisation, Allowing data to be imported from files, Improving the user interface

## How it works:

The program takes a set of paired x and y observations, and then calculates the statistical values needed to construct a linear regression model for the data set provided. The linear regression model consists of y= mx + b Where: m = Slope of the regression line b = intercept x = input value y = predicted value

Once the Regression model has been calculated, the user will be able to enter multiple x values to calculate predictions of the y values.
